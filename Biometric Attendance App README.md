“This was an academic project for my CS 4405 Mobile Applications course. The assignment required building an iOS attendance app with:
User signup with email validation
Password setup
Biometric authentication (fingerprint/face ID)
GPS location verification for office check-in/out
Check-in/out tracking with timestamps
Error handling (no internet, invalid credentials, duplicate check-ins, etc.)

I used Swift, Xcode, LocalAuthentication, and CoreLocation. This was a GUI prototype completed on Replit. Screenshots of the interfaces are included in the repository."
