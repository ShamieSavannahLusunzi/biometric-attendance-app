# Biometric Attendance App

This was an academic assignment for my CS 4405 Mobile Applications course. I designed and built GUI interfaces for an iOS attendance app with biometric authentication.

**Technologies:** Swift, Xcode, LocalAuntentication, CoreLocation

**Key Features:**
- User signup with email validation
- Password setup
- Biometric authentication (fingerprint/face ID)
- GPS location verification for check-in/out
- Check-in/out tracking with timestamps
- Error handling for network failures, invalid credentials, and duplicate check-ins

**Note:** This was a GUI prototype completed on Replit. I do not have an iOS device, so the app was not deployed. Code and screenshots demonstrate the functionality.
